## 🎯 Overview

A production-grade depreciation calculator that bridges accounting principles with software development. Whether you're a CPA candidate preparing for exams, a finance professional needing quick calculations, or a student learning depreciation concepts, this tool delivers accurate, reliable results.

**Live Demo:** [kiariealexn.github.io/depreciation-calculator](https://kiariealexn.github.io/depreciation-calculator/)

## ✨ Features

### ✅ Multiple Depreciation Methods
- **Straight-Line Method** - Equal annual depreciation
- **Declining Balance Method** - 200% & 150% accelerated options
- **Sum-of-the-Years-Digits Method** - Accelerated with declining fractions

### ✅ Interactive Visualizations
- Annual expense comparison chart
- Book value decline visualization
- Cumulative depreciation tracking
- Multi-method side-by-side view

### ✅ Professional Results
- Year-by-year depreciation schedules
- CPA-standard 2-decimal precision
- Beginning/ending book values with accumulated depreciation tracking
- Partial year support (e.g., 5.5 years)

### ✅ User-Friendly Interface
- Clean, intuitive design with real-time validation
- Fully responsive (mobile, tablet, desktop)
- Helpful error messages and input guidance

### ✅ Educational Value
- Method explanations with formulas and examples
- Best-use recommendations for each method
- Interactive side-by-side comparison
